# 超慢跑 Q版陪伴 (Slow Jogging Companion)

🏃‍♀️ **專為超慢跑運動設計的可愛 Q 版網頁陪伴應用**，內建 180 BPM 節拍器、8 大運動主題音樂、首頁輕音樂、角色動態陪伴與即時語音提醒。

- 🌐 **線上免安裝體驗網址**：[https://ll-wood-emerus.github.io/slow-jogging/](https://ll-wood-emerus.github.io/slow-jogging/)
- 📌 **目前版本**：`v=560`

---

## 🌟 主要功能特色

- ⏱️ **專業超慢跑節拍器**：
  - 預設 180 BPM 推薦步頻，可自由調整 120 ~ 240 BPM。
  - 提供 4 種音色（木魚、鼓邊、滴答、電子音效），滿足不同節奏感需求。
- 🎵 **豐富音樂伴跑**：
  - 首頁專屬放鬆輕音樂（`home.mp3`，自動適應微音量）。
  - 8 首精選超慢跑背景音樂（音樂1 ～ 音樂8）。
  - 跑步中支援隨時彈出音量調節選單（點擊外部自動收合）。
- 👯 **Q 版夥伴動態陪伴**：
  - **Saya** ⚡（白髮少女）
  - **Sheath** 🍵（雙馬尾）
  - **Hiiragi** 🌸（包包頭）
  - 完整支援待機散步、站立預備、跑步慢跑以及完成慶祝動作。
- 💬 **語音激勵系統**：
  - 跑步過程中定時給予呼吸引導與姿勢建議。
- 📱 **響應式跨裝置支援**：
  - 自動保持最佳比例，支援手機、平板、筆電與電視全螢幕超慢跑體驗。
  - 跑步時自動保持螢幕恆亮（Wake Lock API）。
